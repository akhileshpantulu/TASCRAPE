TripAdvisor Review Scraper

Version 2, with a progress tracker for each hotel. Runs in your own browser, so no terminal, install or Python is needed. Works in Chrome and Edge. Claude in Chrome (Cowork) can use this same bookmark.

1. Add the bookmark

Show your bookmarks bar (Ctrl+Shift+B, or Cmd+Shift+B on Mac). If you have an older TA Reviews bookmark, delete it. Then drag this green button onto the bar:

TA Reviews

If dragging does not work: right-click the bookmarks bar, choose Add page, name it TA Reviews, and paste the text below into the URL field.

2. Use it by hand

  1. Open one of your hotel pages on tripadvisor.com.
  2. Click the TA Reviews bookmark.
  3. Paste your hotel URLs separated by spaces, or leave the box empty to scrape the hotel you are viewing.
  4. Enter a max number of reviews per hotel, or leave it empty for all.
  5. A tracker panel shows a progress bar for each hotel. Keep the tab open; do not reload it or navigate away. When it finishes, the CSV downloads automatically.

If an orange setup message appears, scroll to the hotel's reviews and click the next-page arrow once.
